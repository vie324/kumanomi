# 睡眠整体サロン SLEEPY — 顧客向けアプリ「スーピーくんと眠ろう」

睡眠をテーマにした整体院 **SLEEPY** のお客様向けWebアプリ(動作するプロトタイプ)です。
ロゴキャラクター「**スーピーくん**」(眠りのひつじ)を育てながら、睡眠の記録・学び・ケア・お買い物までをひとつのアプリで完結させます。

## 🚀 動かし方

ビルド不要の単一HTMLです。`sleepy/index.html` をブラウザで開くだけで動きます
(React / Tailwind / MediaPipe を CDN から読み込むため、インターネット接続が必要です)。

```bash
# リポジトリ直下で
python3 -m http.server 8080
# → http://localhost:8080/sleepy/ を開く
```

スマートフォン表示を前提にデザインしています(PCの場合は幅を狭めると見やすいです)。
データはすべてブラウザ内(localStorage)に保存されるデモデータです。
「マイ」タブ →「せってい」からデモデータのリセット/まっさらな状態への切り替えができます。

## 🐑 スーピーくん育成

- ロゴの羊キャラクターを忠実にSVG化。**呼吸アニメーション・Zzz・タップでの反応**つき
- 睡眠記録・教育・ストレッチ・来店・購入などの行動でXPが貯まり**レベルアップ**
- レベルに応じて **ナイトキャップ → 星のマフラー → 雲のざぶとん → 王冠** と姿が進化
- 昨夜の睡眠スコアに応じて**表情が変化**(ぐっすり=にこにこ / 寝不足=おつかれ顔)

## 主な機能

- **睡眠ノート** — 就寝/起床・寝つき・中途覚醒・ぐっすり度・朝の気分・生活習慣(カフェイン/スマホ/入浴/飲酒/運動)を30秒で記録 → 睡眠スコア(0-100)を自動算出。週間チャート・連続記録・習慣別の教育フィードバック
- **AI睡眠診断** — かんたん診断(来店前)と本診断30問。睡眠の質/生活リズム/自律神経/からだの4軸レーダーと6つの睡眠タイプ判定、タイプ別のホームケア・通い方提案
- **眠りの教科書** — 「日々の行動はすべて自律神経と睡眠につながる」を伝える教育コンテンツ10本(各記事に要点・クイズつき)
- **ストレッチずかん** — 8種のストレッチを秒数タイマーつきで実施。各ストレッチに自律神経への作用解説
- **AI姿勢分析** — カメラ+MediaPipe Poseで正面/背面/側面/座位を点数化(査読論文ベースの基準)。施術前後のBefore/After比較レポートと、姿勢→呼吸→自律神経→睡眠のつながり解説。カメラなしで試せるデモモードつき
- **SLEEPYストア** — ホームケア商品EC(診断タイプ連動のおすすめ表示)・カート・デモ決済・サブスク3プラン。回数券商品の購入で残高に即チャージ
- **回数券** — 残高・利用/チャージ履歴をカードで見える化
- **マイページ** — 来店履歴・姿勢分析履歴・データ蓄積・実績バッジ
