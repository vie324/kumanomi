# くまのみ 統合ポータル

**社内SNS × 経営ダッシュボード × 業務システムを1つに束ねた、くまのみ整骨院・整体院グループのためのオールインワン・ポータル(動作するプロトタイプ)**

ジンジャー(勤怠)・サンクスギフト/TUNAG(社内SNS)・Salon One(予約)・スプレッドシート管理を、
1つの統合ダッシュボードに置き換えることを目的としたデモアプリケーションです。

## 🐑 姉妹アプリ: 睡眠整体サロン SLEEPY 顧客向けアプリ

[`sleepy/`](sleepy/) に、睡眠をテーマにした整体院「SLEEPY」の**お客様向けアプリ**(スーピーくん育成 × 睡眠記録 × AI診断 × 姿勢分析 × EC)が入っています。`sleepy/index.html` をブラウザで開くだけで動作します。詳しくは [sleepy/README.md](sleepy/README.md) を参照してください。

## 🚀 動かし方

ビルド不要・外部依存ゼロの静的アプリです。

```bash
# リポジトリ直下で
python3 -m http.server 8080
# → http://localhost:8080 を開く
```

**GitHub Pages でそのまま公開できます**(Settings → Pages → Branch を選ぶだけ)。

- データはすべてブラウザ内(localStorage)で完結するデモデータです。日付は常に「今日」を基準に自動生成されます。
- 右上の ⚙️ から「デモデータをリセット」できます。
- 🌙 ボタンでダークテーマに切り替わります。モバイル表示にも対応しています。

## 🎨 ブランドについて

くまのみのロゴを軸にした配色・モーション設計になっています。

- **ブランドカラー**:ロゴのオレンジ(`#e2621a` / ハイライト `#f8a423`)を主役に、クマノミが棲む海のティール(`#0c7489`)を相棒色として使用
- **ロゴの配置**:サイドバー(横ロゴ)、起動時のスプラッシュ、AIアシスタントのアバター、空状態、AI生成中の待ち時間、朝のあいさつトースト、favicon
- **動き**:起動時にクマノミが泳いで登場、サイドバーではゆっくり泡が昇り、カードは上から順にふわっと表示、統計タイルはホバーで浮き上がります(`prefers-reduced-motion` を尊重)
- **ロゴ素材**:`assets/kumanomi-wide.png`(横ロゴ)、`assets/kumanomi-mark.png`(クマノミ単体)、`assets/favicon.png`
  ※ メインロゴに含まれる「くまのみ整骨院」の文字は使用せず、キャラクター部分のみを切り出して使用しています。

## 🔐 権限と組織図について

**組織図(傘)が「誰に何が見えるか」を決めます。** 自分の傘の下(配下)にある日報・情報はすべて見えます。管轄は毎月変わる前提のため、**組織図ページでカードをドラッグするだけで付け替え**でき、見える範囲に即時反映されます。

```
社長(熊野)
└ 統括マネージャー(小林)
  ├ マネージャー(加藤)─ 統括院長(大森)─ 院長:成増・大宮
  ├ マネージャー(高木)─ 院長:川越・浦和 / 店長:ビューティー大宮
└ 本部人事(森)… 全店舗の勤怠・シフト(日報は対象外)
```

- **呼称は店舗カテゴリで自動で変わります**:整骨院・整体院・鍼灸院=院長 / 美容・エステ=店長
- **メンター制度**は組織図と別レイヤーで重なります。メンターは担当メンティーの日報も閲覧できます(組織図ページの「🌱 メンター関係」トグルで可視化)
- 組織変更はすべて**変更履歴**に残り、ワンクリックで元に戻せます
- 画面右上のユーザー名から**ログインユーザーを切り替えて**、役職ごとの見え方をその場で確認できます

主なルール:
- **顧客情報・カルテは出勤打刻をしないと閲覧できません**(個人情報保護)。院長・店長以上は緊急対応のため打刻なしでも閲覧できますが、警告バッジが表示されます。
- **シフトは全社員が全店舗を閲覧でき、編集は院長・店長以上**(自分の傘の下にある店舗のみ)。**必要人数ルール・充足判定・他スタッフの希望休の提出状況は責任者のみ**に表示されます。
- **希望休は月単位で申請**します(希望休・有給休暇・特別休暇・誕生日休暇から日ごとに選択)。
- **日報は傘に沿って下りていく形**で見えます。各行に「なぜ見えるか」(自分/メンティー/直属/配下/全社)のバッジが付きます。
- **売上・経営数値は全員が閲覧できます。**
- **テスト点数・スキルスコア・評価は本人と責任者(院長以上)のみ**。一般スタッフに他のスタッフの点数は表示されません。
- **勤怠の承認キューは責任者のみ**。一般スタッフの勤怠画面は打刻と自分のサマリー(出勤日数・遅刻)だけのシンプルな表示です。
- **在庫の発注・入荷は院長以上のみ**(一般スタッフは閲覧のみ)。経費の承認も院長以上です。

## 📦 モジュール構成 — クライアント要望との対応

| モジュール | 置き換え対象 | 実装した要望 |
|---|---|---|
| **ダッシュボード** | スプレッドシート集計 | 経営数値の見える化。売上・契約率・回数券消化率・目標比を自動集計。打刻漏れ/在庫/離反リスクのアラート集約 |
| **チャット** | LINE グループ | グループ・店舗・個別(DM)ルーム、**@メンション**(入力補助つき)、絵文字リアクション、引用返信、既読表示、ルーム内検索、ピン留め、未読バッジ。**モバイルのキーボード表示ずれを補正**(visualViewport対応)。メッセージを**📋ワンタップでタスク化** |
| **ロープレ練習** | 先輩との口頭練習 | トークスクリプトを見ながら**録音 → AIがスクリプトと比較して採点**。行単位の話せた/抜けた判定、網羅率・ペース・フィラー・共感の4指標、改善点と次のアクション、メンターのレビュー |
| **組織図** | 紙の組織図・口頭共有 | **ドラッグ&ドロップで管轄を付け替え**られる組織ツリー。見える範囲のプレビュー、メンター関係のオーバーレイ、変更履歴と巻き戻し |
| **人事管理** | 本部の手集計 | 全店舗の勤怠一覧・承認、**シフト乖離の自動ピックアップ**(遅刻/早退/欠勤/打刻漏れ/予定外出勤)、**残業アラート**(閾値切替)、スタッフ台帳 |
| **社内SNS** | サンクスギフト・TUNAG | サンクスカード(**持ちポイント制なし — 送ると+10pt・受け取るとギフト分が貯まる**)、**画像1〜3枚付きのタイムライン投稿**、連絡事項、朝礼メモ、理念共有、委員会チャンネル、**毎月のお願い(1minuteアンケート・交通費申請)への導線** |
| **日報** | 紙・スプレッドシート | 入力は**個人売上・施術数(新患込み)・新患数・成約数・コメント(振り返り)の5項目だけ**。**提出状況の可視化**(提出率・未提出者への催促)、**権限に沿った階層閲覧**とメンター制度、**日報の中身を見る詳細ビュー**(数値・コメント全文・当日の勤怠・推移・コメント返信)。※報告文のAI処理・AI下書きは行わない方針 |
| **勤怠管理** | ジンジャー | **GPS打刻(店舗200m圏内のみ有効)**。打刻漏れの検知と承認フロー。**承認キューは責任者のみ表示**。一般スタッフのサマリーは出勤日数・遅刻のみのシンプル表示 |
| **シフト管理** | ジンジャー | **希望休は月単位で申請**(希望休/有給休暇/特別休暇/誕生日休暇をカレンダーでタップ選択)。希望と研修予定から**AIがシフトを自動作成**。**週表示に加えて月表示**(カレンダー型/スタッフ×日一覧型)。全社員が全店舗を閲覧でき、編集は責任者以上。**必要人数・充足判定・他スタッフの希望は責任者のみ表示** |
| **予約管理** | Salon One | **ベッド基軸の予約枠**(ベッド×時間)。**予約カードをドラッグして枠を移動**(詳細モーダルからの変更も可)、空き枠クリックで新規予約、LINE/電話/店頭/Web別のソース管理、来院処理で回数券を自動消化 |
| **顧客・カルテ** | 来患ノート・紙カルテ | **出勤打刻をしないと閲覧できないアクセス制御**、**姿勢分析33ポイント自動検出**(グリッド線合わせ不要)、**ボイス入力→AIがSOAPに整形**、施術内容をAIがまとめて**患者様へLINE送信**、回数券・診察券の完全デジタル化、離反リスクのAIリマインド |
| **スタッフ管理** | 手作業のテスト作成・評価 | **テストをAIが自動作成**・受験・採点・実行度合いの可視化。研修出欠(月3回/技術・鍼)。**面談はボイス入力→AIが問題点+ネクストアクションに整理**。評価は日報・テストから自動集計。**点数・評価は本人と責任者のみ閲覧可** |
| **会議・議事録** | 手書き議事録 | マネージャー会議(週次90分)・幹部会議(月次)。冒頭タスクチェック運用、**ボイス入力→AIが議事録+決定事項+アクションアイテムに整形**、**アクションをタスクリストへワンクリック連携** |
| **タスク** | 口頭依頼・付箋 | **チャット(📋ボタン)や議事録から飛ばしたタスクの受け皿**。担当者・期限・発生元(チャット/議事録)付きで、未着手→進行中→完了を管理。ナビに自分の未完了バッジ |
| **在庫・経費** | 小口ノート・レジ手作業 | 発注点アラート付き在庫管理(**発注・入荷は院長以上のみ/一般は閲覧のみ**)、小口現金出納帳、**領収書画像付きの経費申請**、**交通費申請(画像+金額+区間+距離・月1回)**、承認フロー、**mPOPレジ連携**(日次自動同期のシミュレーション) |
| **AIアシスタント** | マニュアル・口頭質問 | **使い方や疑問をすべてAIチャットで質問できる**。FAQ検索付き |

## 🏗 技術構成

```
index.html          … エントリポイント(GitHub Pages 対応)
assets/             … ロゴ素材(横ロゴ・クマノミマーク・favicon)
css/
  tokens.css        … デザイントークン(ライト/ダーク両テーマ・検証済みチャートパレット)
  base.css          … リセット+アプリシェル(サイドバー/トップバー/レスポンシブ)
  components.css    … 共通コンポーネント(カード/ボタン/テーブル/モーダル/AIパネル等)
  pages/*.css       … ページ固有スタイル(ページごとにスコープ)
js/
  app.js            … シェル構築・ナビゲーション・通知・検索・テーマ・ユーザー切替
  auth.js           … 権限(RBAC)エンジン — ランク/メンター関係/出勤状態から可視範囲を決定
  router.js         … ハッシュベース SPA ルーター
  store.js          … 状態管理+localStorage 永続化
  data.js           … デモ用シードデータ(実行日基準で自動生成)
  ui.js             … UI 部品ライブラリ(依存ゼロ)
  charts.js         … SVG チャート(折れ線/バー/ドーナツ/レーダー等、依存ゼロ)
  ai.js             … AI 機能の抽象化レイヤー(デモでは擬似実装)
  pages/*.js        … 各機能モジュール
```

- **フレームワーク・ビルドツール・CDN 不使用**(完全自己完結)。導入判断のためのプロトタイプとして、そのままホスティングできます。
- チャートの配色は色覚多様性(CVD)検証済みのパレットを使用し、ライト/ダーク両テーマで検証しています。

## 🤖 AI 機能について

デモでは `js/ai.js` が擬似的に応答を生成しています。実運用では同ファイルを **Claude API 等の LLM 呼び出しに差し替えるだけ**で、以下がそのまま本物になります:

- シフト自動作成(希望・必要人数・研修の制約充足)
- ボイス入力の書き起こし → SOAP カルテ整形
- カルテ+写真 → 患者様向け LINE メッセージ生成
- 面談メモ → 問題点・要因・ネクストアクションの構造化
- 会議メモ → 議事録・決定事項・アクションアイテム化
- 研修テーマ → テスト問題の自動生成
- ロープレ音声 → トークスクリプトとの比較採点・フィードバック(音声認識 + LLM 評価)
- 社内 FAQ チャットボット
